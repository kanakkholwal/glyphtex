# Security policy

## Reporting a vulnerability

Report it privately through GitHub: https://github.com/kanakkholwal/glyphtex/security/advisories/new

- Do not open a public issue for a vulnerability.
- Include the affected version or commit, steps to reproduce, and the impact you see.
- Expect an acknowledgement within 3 working days and a fix plan within 10.
- We credit reporters in the release notes unless you ask us not to.

## Scope

- The Teams server (`apps/server`), the web app (`apps/web`) and the desktop app (`apps/desktop`).
- Out of scope: findings that need a compromised device or an admin acting maliciously, and denial of service by volume.

## Supported versions

Only the latest release and `main` receive security fixes.
