# Project template attribution

The starter documents come from two places:

- **The public [Overleaf template gallery](https://www.overleaf.com/latex/templates).** Each is redistributed under the licence its author chose, all of which permit it (CC BY 4.0, CC BY-SA 4.0, CC0, MIT or LPPL). Overleaf and the template authors do not endorse GlyphTeX.
- **Written for GlyphTeX**, for the uses the gallery could not cover offline, and dedicated to the public domain under CC0 1.0.

Every template compiled with the GlyphTeX engine before it was included. A project created from one also gets a
`TEMPLATE-LICENSE.md` with this attribution.
