# Accessibility statement

GlyphTeX aims to meet WCAG 2.2 level AA. The product has not been through a formal third-party audit,
so this is a statement of intent and known status, not a conformance claim.

## What is in place

- Keyboard operation for navigation, dialogs, menus, the command palette and the file tree.
- Visible focus rings, semantic landmarks and labelled form fields on the public site, sign-in and settings.
- Colour tokens checked for contrast; light and dark themes; reduced-motion respected for transitions.
- Errors from the compiler are listed in a navigable panel, not only shown in the PDF.

## Known gaps

- The code editor and PDF preview rely on third-party components with limited screen reader support.
- Drag and drop in the file tree has keyboard alternatives for most, not all, actions.
- No formal VPAT or audit report exists yet.

## Report a problem

Email the contact address on the site or open an issue on GitHub. Accessibility reports are triaged
with the same priority as bugs that block a task.
